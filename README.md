🎯 Guess the Number Game

A modern and interactive Guess the Number game built using HTML, CSS, and JavaScript.

The computer randomly selects a number, and the player has to guess it. The game provides hints, tracks attempts, calculates a score, and saves the best score.

🚀 Features

* 🎯 Random number generation
* 🎚️ Three difficulty levels
    * Easy — 1 to 50
    * Medium — 1 to 100
    * Hard — 1 to 500
* 💡 High/low hints
* 🔥 Distance-based hints
* 📊 Attempts counter
* 🏆 Score system
* 💾 Best score saved using localStorage
* 🔄 New Game button
* ⌨️ Press Enter to submit a guess
* 📱 Responsive design for mobile and desktop
* ✨ Modern UI with animations

🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* DOM Manipulation
* Browser Local Storage

▶️ How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open index.html using a browser or VS Code Live Server.
4. Select a difficulty level.
5. Enter your guess.
6. Try to find the hidden number with the highest possible score!

🎮 How the Game Works

The game generates a random number based on the selected difficulty.

For every incorrect guess:

* The game tells you whether your guess is too high or too low.
* Your score decreases.
* You receive a hint based on how close your guess is.

When you guess correctly, the game ends and your score is compared with your saved best score.

This is a simple game.
